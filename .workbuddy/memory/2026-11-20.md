- 补丁 5 个（已在官方 php-7.0.33 全新源码上顺序试打，全部零 reject）：

- 第一轮（run 44738245278）失败：`ext/intl/intl_convertcpp.h:29 unknown type name 'UnicodeString'`，
  clang 提示 `did you mean 'icu_78::UnicodeString'`。
  根因：ICU 78 的 `unicode/uversion.h` 里 `U_USING_ICU_NAMESPACE` 两个分支都恒为 0，
  不再自动 `U_NAMESPACE_USE`；而 PHP 7.1.33 的 `PHP_SETUP_ICU` pkg-config 分支里硬写了

  从不设 ICU_CXXFLAGS —— 这才是 7.1 能过、7.0 报错的真正原因（与 -std=c++17 无关）。
- 修复：`CXXFLAGS` 追加 `-DU_USING_ICU_NAMESPACE=1`（该宏只在 `#ifdef __cplusplus` 内生效，
  加到 CFLAGS 无意义）。commit `2dcf601`，重推 tag 后 run 44739672157 **success**，
  release `php-7.0.33` 产出 `php-7.0.tar.xz`（12.16 MB）。

## php-5.6 关键结论：官方 5.6.40 无法配 OpenSSL >= 1.1

- run 44743252159 失败于 `ext/openssl/openssl.c:3563 incomplete definition of type 'DSA'`
  （`dsa->p`/`dsa->priv_key`）。OpenSSL 1.1.0 起 DSA/DH/RSA 结构体 opaque 化，
  官方 php-5.6.40 的 ext/openssl 只支持到 1.0.2（全文 0 处 `0x10100000` 分支）。
- `patch/php/0002-...OpenSSL-3.0-patch-PHP5.6.patch` 只有 33 行，只补 `OPENSSL_free` 与 MINIT，
  不解决结构体 accessor 问题。
- 仓库里原本没有 `0014-Fix-default-LDAP-host-PHP5.6.patch`，已从 php-src-backports 拉取补入。
- **正解（shivammathur/homebrew-php php@5.6 的做法）**：不要用 php.net 官方 tarball，
  改用 `shivammathur/php-src-backports` 的 security-backports-openssl11 线源码
  （formula 钉 commit `048228913b6eeda72b784c59c43a7bfe8eb05f34`，2026-11-19）。
  实测该树已内置全部 8 个补丁（逐个 dry-run 全部 "Reversed/previously applied"）：
  0001 ICU70、0002 OpenSSL3、0003 TLS EOF、0004 aarch64 乘法、0005 pthreads、
  0006 ITIMER_REAL、0008 register、0014 LDAP；`ext/openssl` 含 `DSA_get0`×5 与 `0x10100000`×4。
  formula 直接 `--with-openssl=openssl@4`，无任何 openssl 补丁。
- formula 额外只做：`buildconf --force`；`:DATA` 补丁改 `acinclude.m4`
  （PHP_ADD_LIBPATH/PHP_ADD_INCLUDE 跳过 SDK 内 usr/lib、usr/include；PHP_SETUP_ICONV 认 `.tbd`）
  和 `Zend/zend_compile.h`+`Zend/zend_execute.h`（EX_TMP_VAR / EX_TMP_VAR_NUM 宏改 static inline）；
  ENV 用 `-std=gnu99`（不是 gnu17）+ `-Wno-incompatible-function-pointer-types -Wno-implicit-int
  -Wno-int-conversion`（clang>=1500）、`-DU_DEFINE_FALSE_AND_TRUE=1`（C+CXX）、
  `CPPFLAGS -DU_USING_ICU_NAMESPACE=1`、`CXX=-std=c++17`、`ENV.libcxx`。
- 该树 `PHP_SETUP_ICU` 仍是 icu-config 单路径 → 仍需 `--with-icu-dir` + 手工 `-DU_USING_ICU_NAMESPACE=1`。
- 待办：5.6 脚本改为下载该 commit tarball + buildconf，去掉 8 个 patch，ENV 对齐 gnu99。
